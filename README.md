# Victoria Fashion — Bespoke Nigerian Couture

An ultra-luxury digital atelier for **Victoria Fashion**, a premier bespoke fashion house handcrafted in **Akwa Ibom, Nigeria**.

The entire codebase is built with pure, standard **HTML5, CSS3, and modern vanilla JavaScript** with **zero build tools, bundlers, or Node.js dependencies required**.

---

## 🚀 Quick Start

To open and browse the website:
- **Double-click [`index.html`](file:///c:/Users/HP/Desktop/victoria%20fashion/index.html)** in Windows File Explorer.
- The website opens immediately in your default browser and works completely offline or online.

## 💎 Features & Lookbooks

1. **Home**:
   - Apple.com-style keynote hero with 3D depth layering.
   - Dedicated showcase sections for Men, Women, Children, and Occasions.
   - Direct WhatsApp consultation booking.

2. **Catalogue (80 Creations)**:
   - 80 bespoke looks categorized into:
     - All Collections (80)
     - Men Wears (20)
     - Female Wears (20)
     - Children Wears (20)
     - Occasions (20)
   - Dynamic instant filtering and pre-filled WhatsApp sewing order links.

3. **Occasions & Celebrations (Option A Ceremonial Cathedral Archway)**:
   - **Level 1 Portal**: Choose between **Weddings** and **Other Celebrations** framed in grand cathedral archways against a gold arch lattice pattern.
   - **Level 2A Weddings**: Single grand cathedral arch with **Front View** and **Back View** toggle buttons, embroidery details, and fabric specs.
   - **Level 2B Other Celebrations**: Dual cathedral archways presenting coordinated **MALE VERSION** and **FEMALE VERSION** ensembles side-by-side (Aso-Ebi, Chieftaincy, Thanksgiving).

4. **Service Experience (Bugatti.com Style)**:
   - Full-width sequential scrolling video banners one after another.
   - Seamless borderless edge vignettes fading into black with no outlines.
   - Centered English typography and Bugatti-style pill outline buttons.

5. **Children Lookbook**:
   - 50% dimmed star outline background pattern on black.
   - Slanted parallelogram cards for Junior Prince (sky blue) and Little Princess (gold).

6. **Women Haute Couture**:
   - Repeating Love Heart outline pattern on dark rose (`#0d050c`) background.
   - Slanted cards for Front View and Back View with ambient rose glows.

7. **Men Lookbook**:
   - Modern architectural grid pattern background.
   - Slanted cards showcasing Front View and Back View tailoring.

8. **WhatsApp Consultation Modal**:
   - Interactive department selector (Men, Women, Children, Occasions).
   - Custom style/notes input that formats a message directly to Victoria in Akwa Ibom.
